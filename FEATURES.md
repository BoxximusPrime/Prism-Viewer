# Prism Feature Inventory

This document tracks major features and user-facing customizations added to Prism beyond the official Second Life viewer.

The committed feature list is based on the differences from the `upstream/develop` branch, the Prism commit history, and related development notes. Current uncommitted changes may include additional work in progress and should not be treated as final until committed.

- Local water reflections use precise ray hits, a continuous grazing-angle fade, and depth-plane reconstruction to remove scanlines on walls and beneath docks. Depth gradients reject sky neighbours and preserve thin posts/silhouettes. Rays begin at the actual water surface and bracket contact immediately, removing the reflection gap beside vertical meshes; receiver-height checks follow displaced troughs. GPU regressions cover camera motion/tilt, multiple resolutions, wall contact down to 1 mm, crests/troughs, and sky/submerged rejection. (0.6.0; user confirmed the earlier general reflection fix; 527 GPU checks, combined dock/contact Release build and viewer shader startup/clean shutdown passed; in-world verification pending)

- Experimental surface displacement uses the existing FFT swell/chop heights. Fixed 25 cm world-space samples extend across a selectable 8-128 m radius (default 64 m), with a continuous outer fade and a guarded mesh window that moves only outside visible displacement. Chunked index buffers preserve detail over larger areas; region/void edges share samples, culling includes troughs, and the exclusion pass uses the same geometry. Graphics > Water adds an independent displacement toggle, height (0-5), detailed distance, wind/wave speed (0-3x, phase-preserving) and shallow-wave damping (0-1, full height by 1.5 m depth). Disabling displacement preserves the selected height/distance and returns to the inexpensive flat mesh. This is visual displacement: simulator level, underwater classification and volume optics retain the mean plane; damping only sees visible opaque geometry. (in progress; uncommitted; Release build, 451 native grid cases, 7 production wave-clock checks, 714 GPU checks, shader startup and all 22 live Water controls with Default/OK/Cancel passed; in-world appearance/performance review pending)

- Texture-filter changes activate their intended texture unit even after a cached bind. This prevents mipmapped water-wave bindings from changing unrelated UI white textures or water exclusion masks, which can black out colour swatches/visualizers and remove the water surface. (in progress; uncommitted; native C++/GPU regression reproduces both black textures and misdirected mip generation with the old code; 18 texture-state, 685 water/wave/caustic and 17 UI backdrop checks, Release build, shader startup and live Water colour-picker/Default/OK/Cancel checks passed; user confirmed both surface visibility and UI colours fixed in-world)

- Water wave generation saves/restores the caller's colour-write mask and enables all RGBA channels throughout the FFT and slope resolve. This fixes undefined chop data when caustics trigger the simulation before deferred lighting, where scene alpha writes are disabled, corrupting surface normals. (in progress; uncommitted; RGB-only failure reproduced on GPU; 685 water/wave/caustic checks including four restricted-mask regressions and Release build passed; user confirmed surface visibility restored with the additional texture-unit fix)

- Above-water refraction uses a bounded, depth-aware wave distortion relative to the flat interface. Visibility limits retreat the sampling coordinate instead of blending two scene images, addressing the lifted/doubled submerged mesh. Existing RGB water transport adjusts to the new lookup without applying haze twice. Sun/sky attenuation, clarity and separate optional transmission/scattering colours remain available. Transparent layers still approximate depth with the opaque scene. (in progress; uncommitted; Release build, 882 water/wave/caustic GPU checks, existing transparency/projector checks, uncached shader startup and all 17 live Water controls with Default/OK/Cancel passed; in-world appearance/performance review pending)

- Water caustics concentrate directional sunlight/moonlight on submerged receivers using the same current-frame FFT slopes, wave phase, size, orientation and strength as the surface. A bounded inverse refraction/Jacobian solve filters small detail, attenuates with water depth, respects receiver shadows and exclusion masks, and leaves emission/ambient light unchanged. Graphics > Water adds Caustics strength (0-3, default 1); evolving waves are required. Surface roughness now reaches 0, with a stable direct sun lobe and subpixel filtering. This is a filtered single-path approximation; multi-path focusing at folds and the surface's decorative normal-map detail are not simulated. (in progress; uncommitted; analytic focusing/phase/flat-surface/depth/exclusion/HDR checks and live roughness-zero/caustic control checks passed; in-world tuning pending)
