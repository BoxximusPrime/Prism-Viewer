# Prism Viewer 0.6.2

This Windows release focuses on temporal stability, shadows, skin scattering,
and Photo Tools controls.

- **TAA stability** adds fine static-detail protection, repeated-flicker
  detection, bounded history retention, improved motion/reactive handling, and
  new diagnostics for history rejection and flicker protection.
- **Post sharpening** provides a separate optional sharpening pass after
  antialiasing for TAA, FXAA, SMAA, and snapshots.
- **PCSS shadows** improve blocker search, camera-orbit stability, cascade
  depth generation, and receiver precision. Graphics exposes a saved shadow
  pattern stabilization control.
- **Skin scattering and lighting** improve focused transmission depth,
  grazing blur behavior, alpha/cutout lighting, and shader cache invalidation
  after GLSL changes.
- **Photo Tools** adds aspect-ratio crop bars and keeps composition guides
  aligned to the visible capture area. Saved images continue to exclude the
  guides and crop bars.
- **Picking and materials** improve filtered object selection, specular
  antialiasing, and glTF/PBR alpha lighting behavior.
- **Graphics defaults** incorporate the latest tuned TAA, GTAO, PCSS, SSS,
  and post-processing values while preserving saved user preferences.

## Windows installation

Download the `Prism_0_6_2_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences. A SHA-256 checksum file is included.
