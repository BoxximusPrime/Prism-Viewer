# Prism Viewer 0.6.3

This small Windows release bundles UI sound, pose, inventory, and presentation
polish.

- **UI sound controls** add the current Prism sound customizations and clearer
  sound preference controls.
- **Pose Studio and appearance** improve pose handling, drag interactions, and
  shape-editing controls.
- **Inventory** keeps the existing inventory workflow while refining wearable
  editing and related interaction behavior.
- **Prism presentation** refreshes the landing page, gallery assets, and site
  navigation.
- **Bundled resources** remove obsolete UI sound files from the shipped tree.

## Windows installation

Download the `Prism_0_6_3_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences. A SHA-256 checksum file is included.
