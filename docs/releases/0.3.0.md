# Prism Viewer 0.3.0

This Windows release adds graphics options, rendering improvements, and tools
for inspecting lights and reflection probes.

- Refreshed skin scattering, PCSS, GTAO and TAA defaults, with OIT enabled.
  Higher automatic graphics presets use TAA and Sun/Moon shadows; existing saved
  preferences are preserved.
- Charcoal-and-amber graphics tabs with raised selection and hover feedback.
- Temporal antialiasing (TAA), with motion and transparency protection, fine-detail
  stabilization, sharpening, and a dedicated graphics preferences tab.
- Optional GTAO ambient occlusion, with quality, radius, strength, and diagnostic
  controls; legacy SSAO remains available.
- Skin scattering and PCSS soft-shadow improvements.
- A live **Use exact transparency (OIT)** graphics toggle to switch between OIT
  and legacy alpha blending.
- Improved alpha texture batching that reuses texture slots and avoids unnecessary
  batch splits while preserving transparency order.
- Optional light-source and reflection-probe markers in **Build > Options**, plus
  support for projector lights that do not cast shadows.
- Tracy GPU profiling enabled in Tracy builds, with additional alpha and water
  timing scopes.

## Performance tip

In scenes with lots of transparent surfaces and water, **Screen Space Reflections**
can be expensive even with shadows disabled. Turn it off under **Preferences >
Graphics > Advanced Settings** to compare. Reflection probes remain available.
Existing saved preferences are preserved when upgrading.

## Windows installation

Download the `Prism_0_3_0_*_x86_64_Setup.exe` asset. This is an unsigned Windows
x64 installer. It uses the separate Prism installation and profile directories.
Keep your existing Prism preferences when upgrading. A SHA-256 checksum file is
provided with the installer.

The new graphics and editing options remain under active development; testing
across more hardware and scenes is ongoing.
