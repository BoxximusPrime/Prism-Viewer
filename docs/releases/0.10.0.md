# Prism Viewer 0.10.0

This release adds partial-outfit Collections, Quick Photo and experimental hair
physics, with rendering and graphics-preference improvements.

- **Collections** organizes partial looks into categories and sets under
  `#Prism/Collections`. Sets use inventory links, preserve unrelated worn items,
  and offer a separate editor with layer ordering, photos and gallery/list views.
  Switching sets removes the previous set's clothing and attachments while
  retaining shared items and essential body parts. Deleted sets go to Trash.
- **Quick Photo** creates inventory and outfit photos with framing presets,
  backgrounds, attachment visibility and a local pose. Collection photos can
  isolate set items. Experimental mannequin mode keeps clothing colored while
  greying the selected avatar/body surfaces; baked skin and clothing cannot be
  separated. Transparency uses isolated Exact OIT buffers and requires OpenGL
  4.3. Upload cost is shown before the paid upload.
- **Experimental hair physics** uses radial ropes with inertia, gravity and
  animated local-avatar mesh collision. Rendering and physics have independent
  switches, with controls grouped into separate Hair subtabs. Hair self-collision
  and authored strand topology are unsupported.
- **Hair rendering** adds a camera-distance limit and a default-on For me only
  setting. Highlights use texture V for strand direction; automatic flow detection
  and direction previews have been removed. Brightness compensation preserves
  dark-hair highlights, and shader work avoids unused lighting calculations.
- **Rendering refinements** keep your avatar and its attachments at the highest
  available mesh LOD, improve narrow-caster PCSS sampling and skin-transmission
  distance fades, and remove obsolete TAA flicker detection and PCSS stabilization
  controls. Shader compilation refills completed batch slots without waiting for
  the slowest program; hair compute shaders also compile together.
- **Graphics preferences** expose VSync and Maximum FPS, with improved frame-cap
  timing. Updated shipped defaults cover skin scattering, hair rendering/physics,
  ground fog, volumetric-fog lighting and post sharpening. Existing saved choices
  remain subject to the welcome screen's opt-in defaults update.
- **Everyday workflows** add outfit creation-date sorting, pose cycling arrows,
  shared Prism info icons and a compact Collections layout.

## Windows installation

Download the `Prism_0_10_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences. A SHA-256 checksum file is included.

See [the feature inventory](https://github.com/BoxximusPrime/Prism-Viewer/blob/v0.10.0/FEATURES.md) and its linked performance reports
for detailed behavior, measurements and limitations. Broader hair appearance,
performance and some in-world workflow checks remain pending.
