# Prism Viewer 0.6.0

This Windows release adds assisted inventory sorting, more precise building
controls, and an optional way to adopt updated graphics defaults.

- **LLM inventory sorting** suggests destinations for up to 200 selected items
  or folders using your configured OpenAI-compatible connection. Review and
  change suggestions before approving moves or creating categories. Folder
  contents stay together. The command appears when a connection is configured.
- **Building and snapping** adds a center handle for free movement and
  Ctrl+Shift placement against rendered mesh or terrain. With grid snapping
  disabled, hold Shift to temporarily snap move, scale and rotation handles.
- **Graphics default updates** offer the release's tuned settings on startup
  when shipped defaults changed and your saved values differ. Reset or keep
  your settings; either answer is remembered for that version. Matching
  settings and releases with unchanged defaults advance silently. Covers SSS,
  GTAO, TAA, PCSS, Water, Volumetric Fog, Bloom and eye adaptation.
- **Graphics tuning and controls** adopt the current saved tuning as the 0.6.0
  baseline across 87 settings. Eye adaptation is included in the upgrade
  checker. Shadows preferences expose resolution, cascade count and cascade
  distribution. SSS now always uses the optimized diffusion/transmission
  filter; the Maximum quality option has been removed.
- **Rendering fixes** improve water reflections near walls and docks, TAA
  history stability and transparency handling, legacy glow filtering, and
  eye-adaptation metering and tone-mapping behavior.
- **Everyday usability** fixes nested scrollbars in expanded outfits, allows
  Enter to focus nearby chat from non-text controls, preserves Pay and Touch
  with the optional left-click blocker, and improves overflowing graphics tabs.

The exact graphics baseline is recorded in
[0.6.0-graphics-defaults.json](0.6.0-graphics-defaults.json).

## Windows installation

Download the `Prism_0_6_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences; the graphics reset is optional.
A SHA-256 checksum file is included.

Release validation passed 26 native/GPU test scripts, the Release build,
installer extraction and payload checks, and a live graphics-reset/silent-restart
check using isolated preferences. Build: **0.6.0.54508**. Testing across more
hardware and in-world scenes remains ongoing.
