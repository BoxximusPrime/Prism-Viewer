# Prism Viewer 0.9.0

This release adds experimental hair lighting, local Poser previews and wearable
comparison, with rendering, animation and everyday workflow improvements.

- **Experimental hair lighting** adds an opt-in Graphics > Hair panel with
  strand-direction detection, directional highlights, scattering, optical
  thickness, strand variation and brightness compensation. Supports legacy/PBR
  and transparent hair. Focused opacity-based transmission covers the nearest
  visible hair subject within 32 m; direction and density remain approximations.
- **Poser live link** previews animation on your own avatar from the same
  computer, with a matching-code accept/reject dialog for each connection.
  Posing, playback and scrubbing remain local and are never uploaded or broadcast.
- **Compare Items** cycles previews of 2–16 tattoo, eye or skin wearables of the
  same type. A paused choice is shared after two seconds; Cancel restores the
  starting look, including choices already shared.
- **Rendering** reduces avatar and attachment mesh crawl at skybox altitudes.
  Supported drivers compile independent shader programs in asynchronous batches,
  while compilation continues to service simulator pings and acknowledgments.
- **Animation Overrider** fixes ordinary object sits, suspension for furniture
  animations and resumption afterward, and excludes avatar-sourced animation
  echoes from furniture detection to prevent repeated stop/restart loops.
- **Auto Height** ignores hidden footwear geometry, prioritizes common footwear
  names, adds an extra offset control and allows camera interaction while open.
- **Building and inventory** refine temporary Shift grid snapping and protect
  text entry from inventory quick-bind traversal and stale shortcut suppression.
- **Graphics preferences** default GTAO denoising to zero with TAA and offer
  additional smoothing when switching to another antialiasing mode.

## Windows installation

Download the `Prism_0_9_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences. A SHA-256 checksum file is included.

See [the feature inventory](../../FEATURES.md) for detailed behavior and
verification status. Broader hair appearance/performance and some in-world
workflow checks remain pending.
