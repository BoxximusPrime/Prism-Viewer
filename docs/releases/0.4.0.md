# Prism Viewer 0.4.0

This Windows release adds volumetric fog and Pose Studio, improves rendering,
and makes custom graphics settings easier to reset.

- **Default buttons** at the top right of Skin Scattering, PCSS, GTAO, TAA and
  Volumetric Fog reset each page to its shipped settings. Cancel can undo the reset.
- **Volumetric fog** from tagged box prims, with intensity, quality, local-light
  and shadow controls in a dedicated graphics tab. Volumetric fog is off by
  default; skin scattering, PCSS, GTAO and TAA are enabled by default.
- **Pose Studio** under Avatar, with self-avatar pose capture, grouped joint
  controls, rotation editing and session restoration. Poses remain local to the posing session;
  Pose Studio has no animation export or inventory upload.
- **PCSS shadows** gain depth-precision, contact and penumbra improvements,
  plus adjustable cleanup smoothing.
- **Skin scattering** gains overlay rendering and improved shadow interaction.
- **TAA** gains more stable fine-detail handling, depth-aware history sampling,
  corrected post-TAA depth-of-field sampling and expanded debug views.
- Updated skin scattering defaults: diffusion depth 0.012 m, maximum distance
  43 m, penetration 80 mm, optical absorption 9, transmission 4 and transmission
  smoothing 43 mm. Shadows default to Sun/Moon + Projectors with PCSS enabled;
  higher automatic graphics presets also select Sun/Moon + Projector shadows.

## Windows installation

Download the `Prism_0_4_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Existing saved preferences are preserved when upgrading. A SHA-256 checksum
file is included.

These rendering and editing features remain under active development; testing
across more hardware and in-world scenes is ongoing.
