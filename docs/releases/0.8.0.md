# Prism Viewer 0.8.0

This release expands Prism's rendering, camera, inventory and building tools,
and introduces a welcome screen for choosing your graphics and movement setup.

- **Volumetric clouds** follow the environment's cloud coverage with local
  density, lighting and quality controls. Updated defaults enable volumetric
  clouds and include revised lighting, water and post-processing tuning.
- **Ground Fog** adds an optional environment-driven volumetric haze layer,
  with height, range, start distance, fade-in and patchiness controls. Transparent
  surfaces receive fog at their own depth. Ground Fog, Volumetric Fog and SSGI
  remain off by default.
- **Lighting** improves local-light selection on transparent surfaces to reduce
  inconsistent illumination and brightness popping.
- **Welcome to Prism** offers optional graphics-default updates and a camera
  and movement bundle after login. Fresh profiles receive the shipped effect
  defaults; existing profiles can choose whether to replace their tuning.
- **Camera and movement** add independent orbit, dynamic shoulder-camera height
  tracking, shoe-based hover-height calculation and animated-eye mouselook
  options. Experimental swimming has been removed.
- **Inventory** improves keyword sorting and folder highlighting, search
  expressions, equipped counts, attachment progress indicators and optional
  keyboard shortcuts, including outfit views.
- **Building** refines the inspector, surface and vertex snapping, transform
  controls, linked-part navigation and local mesh workflows. A new help window
  explains Prism's placement and snapping gestures.
- **Everyday interface improvements** include borderless fullscreen, mention
  triggers, text editing and notification fixes, and updated window-open audio.
  Obsolete Linden update controls have been removed; Prism's own update check
  continues to use the online version manifest.

## Windows installation

Download the `Prism_0_8_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences. A SHA-256 checksum file is included.

See [the feature inventory](../../FEATURES.md) for detailed behavior and
verification status. Some in-world appearance and performance checks remain
pending, including a known volumetric-fog silhouette issue.
