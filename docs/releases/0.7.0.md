# Prism Viewer 0.7.0

This release adds avatar posing and movement tools, experimental screen-space
global illumination, broader inventory controls, and an update check on login.

- **Pose Studio** adds local pose editing, rotation and position offsets,
  selected-bone gizmos, and hand/foot inverse-kinematics controls. Poses remain
  local to your session; animation export and upload are not included.
- **Experimental swimming** adds an optional water movement mode with surface
  treading, diving, shore exit, and AO swim states. It applies to deep Linden
  water; prim pools and simulator water physics are not supported.
- **Screen-space global illumination (SSGI)** adds optional local diffuse
  bounce with quality, denoising, and diagnostic controls. It is off by default;
  off-screen, transparent, and late fullbright lighting remain outside the
  effect.
- **Inventory** adds folder keywords, configurable folder actions, keyboard
  expand/collapse controls, and attachment-folder helpers.
- **World tools** add Area Search for nearby objects, parcel boundary walls,
  avatar movement and camera options, and improved backward walking behavior.
- **Login** checks the online version manifest and reports when an update is
  available. A failed check does not prevent login.
- **Interface updates** refine nearby chat, Pose Studio controls, sound
  preferences, Quick Prefs, and other everyday viewer interactions.

## Windows installation

Download the `Prism_0_7_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Upgrading preserves saved preferences. A SHA-256 checksum file is included.

See [the feature inventory](../../FEATURES.md) for detailed behavior and
verification status. Rendering, swimming speed, and some in-world UI checks
remain in progress.
