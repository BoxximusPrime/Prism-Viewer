# Prism Viewer 0.5.0

This Windows release introduces a unified photography workspace, substantially
upgrades water rendering, and adds advanced eye-adaptation controls.

- **Photo Tools** replaces the Snapshot entry with a resizable live composition
  workspace for camera movement, focus, lighting, color grading, capture and
  export. It includes focus picking and locking, manual focus distance,
  Dutch/yaw/pitch offsets and resets, visual-effect freezing, and independent
  UI and HUD visibility controls.
- **Water rendering** adds evolving FFT swell and chop, optional geometric
  displacement, shallow-water damping, local reflections, improved Fresnel/GGX
  lighting and refraction, depth-aware underwater transport, and sunlight
  caustics. The Water graphics page exposes the new controls and ships with the
  tuned 0.5.0 defaults.
- **Advanced eye adaptation** adds independent brightening and darkening limits,
  target brightness, highlight protection and separate dark/light adaptation
  times. It is enabled by default with the tuned 0.5.0 settings and works with
  legacy skies without modifying their lighting.
- **Photo finishing** adds live HDR exposure and optional contrast, saturation,
  warmth/tint and lift/gamma/gain grading, shared by the world view and saved
  photo.
- **Volumetric fog** gains an independent direct-light effect control and
  additional quality/performance refinements.
- **Interaction and rendering fixes** preserve scripted touch while blocking
  unwanted special left-click actions, prevent texture-filter state from
  affecting unrelated UI/render targets, and improve water, shadow, skin,
  transparency and temporal rendering behavior.

## Windows installation

Download the `Prism_0_5_0_*_x86_64_Setup.exe` asset. The installer is unsigned
and uses the existing separate Prism installation and profile directories.
Existing saved preferences are preserved when upgrading. A SHA-256 checksum
file is included.

These rendering and photography features remain under active development;
testing across more hardware and in-world scenes is ongoing.
