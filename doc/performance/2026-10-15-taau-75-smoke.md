## GPU and resource checks

- 58 new TAAU GPU/integration checks passed, using 73x49 inputs and 97x65 outputs to exercise odd-size rounding. Covers HDR/borders, output-grid history lookup, motion reprojection, offscreen/depth rejection, reactive rejection, render-corner motion/fog scratch copies, glow alpha, CoC and final physical depth.
- Synthetic diagonal-edge reconstruction: 80 frames with a 16-phase jitter sequence, measuring the final 32 frames against 8x8 supersampled coverage in compressed HDR space. Mean squared error was 0.0000353 for accumulated TAAU versus 0.0003549 for single-frame reconstruction. This is a controlled reconstruction check, not a general image-quality score.
- Existing native TAA suites: 109 core, 29 stability, 20 post-depth, 12 composition and 95 fine-detail checks passed (265 total; 323 including TAAU).
- XML, preference binding/default/persistence, panel bounds and spacing passed. All modified shaders, settings and UI resources match the Release staging directory. `git diff --check` passed.
- Additional photo-tools UI automation was not run in its required LEAP harness; a standalone thumbnail test was blocked by sandbox temporary-directory permissions. The actual full-resolution snapshot and live-mode restoration were checked through MCP above.

## Remaining limits

Broad live comparisons of motion, hair/foliage, disocclusion, resize, DoF controls, preference Cancel/Default and non-default debug resolution divisors remain unverified interactively. Tests validate the relevant shader coordinate paths but do not replace those visual checks. Performance conclusions require warmed, repeated captures in representative scenes with matching live TAAU visual comparisons. Native TAA remains the default.
