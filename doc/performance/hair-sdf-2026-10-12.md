Status: implementation and validation complete; uncommitted. Automated
geometry/shader checks, clean and final Release builds, paired live captures,
post-fix smoke test and final startup shader-count verification passed.

## Implementation

Graphics > Hair keeps Basic avatar collision and adds Animated mesh SDF
collision (self only), off by default. When both are selected, a valid SDF takes
priority; the basic proxies remain the fallback. Other avatars retain their
existing basic mode. The existing size and wire-outline controls explicitly
apply to basic proxies. Reset includes the new checkbox.

The local avatar's mesh body/head selection reuses SSS object selection, excluding
hair and SSS overlays. Selected mesh triangles and weights are cached on upload
or LOD change; mesh-load notifications invalidate cached input. Each frame, a compute shader skins them using the current renderer
matrix palette and bind shape, then builds signed point-to-triangle distances
near their animated surfaces. No per-frame CPU vertex skinning or GPU readback
is required. Fully transparent faces are omitted; texture cutouts are not sampled.

The 96-cubed grid spans a two-metre cube centered 0.3 m below the head in world
space (about 2.08 cm cells). It stores a three-cell near-surface band, about
6.25 cm. Hair contact sweeps through the band rather than testing only the end
position. Two contact sweeps retain tangential movement and preserve authored
overlap. Softness is bounded to 1.5 cells. Pinned roots use the existing path.

Two R32F textures preserve current and previous fields for colour, depth, shadow
and temporal rendering; one uint scratch grid supports atomic nearest-distance
selection. Together those grids use 10.125 MiB, plus cached mesh input at 144 bytes
per triangle. Texture/buffer resources are released when unused or on renderer
cleanup. OpenGL 4.3 compute support and successful shader compilation are required.

The field is a collision approximation around animated mesh surfaces, not a
watertight solid-volume reconstruction. Deep authored overlap, holes, intersecting
body layers, texture transparency and geometry outside the cube remain limitations.
Classic non-mesh avatars use the basic fallback. Adjacent hair cards can still
deform differently; this does not add strand constraints or hair self-collision.
